Where can guests reach this app?

This gets encoded in the QR code guests scan on the TV screen — it needs to be an address their phones can actually reach, not the server's own localhost. We pre-filled it with the address you're using to view this very page, which is usually correct: if you're on the same Wi-Fi guests will be on, that address works for them too. Typically looks like 192.168.x.x:8000. You can come back and change this any time — for example if your router assigns a new IP after a restart — without needing to redo anything else.
