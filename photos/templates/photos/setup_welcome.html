Welcome 👋

Let's get this app ready for your first event — a short guided setup, entirely from your browser. No config files to edit, no terminal commands to run after this point. You can always come back and revisit any step later using the links above.

Here's what we'll set up, in order:

  1. Admin account — your login for the staff dashboard and Django admin.
  2. Google Drive (optional) — automatic photo backup to a Drive folder of your choice. Skippable, can be turned on later.
  3. Network address — confirms the address guests' phones will use to reach this app, so the QR code on the TV screen actually works.
  4. First event — name the "soirée" your guests will upload photos to.
